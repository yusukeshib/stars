# Notebook examples

These examples are the Phase 3 bridge before full Python bindings land. They
use schema-versioned JSON sessions plus the Rust CLI/example binaries so a
notebook, the web UI, and `apps/cli` can all point at the same scene inputs.

## Files

- `session_reproducibility.ipynb` — Jupyter walkthrough: load preset JSON
  sessions, compare pinned solar-system tables, and render the same scene via
  the CLI.
- `session_reproducibility.py` — standard-library companion module / script used
  by the notebook; it is also convenient for CI or headless checks.
- `expected/*-session-table.csv` — pinned astronomy tables generated by
  `cargo run -p stars-cli --example session-table -- <session.json>`.

## Run without Jupyter

From the repository root:

```bash
python3 examples/notebooks/session_reproducibility.py --check-tables
```

Render the same JSON session that the web/desktop hosts can load:

```bash
python3 examples/notebooks/session_reproducibility.py --render tokyo-tonight
```

Rendering requires the normal CLI prerequisites, including a downloaded HYG
catalog (`make setup`) and a working `wgpu` backend. The tabular check does not
need the star catalog or a GPU.

## Refresh pinned tables intentionally

If an astronomy model changes deliberately, regenerate the expected CSVs and
review the numeric diff in the same PR:

```bash
cargo run -q -p stars-cli --example session-table -- \
  docs/presets/sessions/tokyo-tonight.json \
  > examples/notebooks/expected/tokyo-tonight-session-table.csv
cargo run -q -p stars-cli --example session-table -- \
  docs/presets/sessions/moonlit-night.json \
  > examples/notebooks/expected/moonlit-night-session-table.csv
```
